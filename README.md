# futo（フト）
> タイムを捨てて、領地を育てる。走った道が色で育つランニングアプリ。

![Language](https://img.shields.io/badge/language-TypeScript-blue)

---

## 🎯 解決する課題

ランニング初心者の多くが「タイムが遅い」「目標設定が面倒」という理由で挫折している。

**futoはタイム・ペース・距離を一切表示しない。**
代わりに「走った道が色で育つ」という体験で、ランニングを生涯の習慣に変える。

---

## ✨ 主な機能

| 機能 | 説明 |
|------|------|
| 🗺️ **ヒートマップ** | 走った道が色づき、通過回数で緑→黄→オレンジ→赤に変化 |
| 🚩 **フロンティアマーカー** | まだ走っていないエリアに旗を自動配置。今日の目的地を提案 |
| 🏅 **称号システム** | 累計ラン数に応じて5種類の称号が解除される |
| 📊 **統計画面** | 総ラン数・総走行時間・総開拓マス数・称号プログレスバー |
| 🔔 **デイリーミッション通知** | 毎朝7時に「北方向に500m開拓せよ」などのミッションを通知 |
| 🎬 **3段階カスケード報酬** | 走り終わると演出が3段階で展開。ガチャを開ける感覚 |
| ⚙️ **通知設定** | 通知のオン/オフをユーザーが自由に設定可能 |

## 🏗 システム設計

### GPS取得ロジック
- 取得頻度: 距離5m移動ごと（`distanceInterval: 5`）
- 精度: `Accuracy.Balanced`（速度とバッテリーのバランス）
- バックグラウンド動作対応

### ヒートマップ設計
- グリッド方式: 地図を30m×30mのマス目に分割
- 通過回数をグリッドIDをキーとしたオブジェクトで管理
- `useMemo`で全セッション+記録中ルートの通過回数を効率的に集計

### データ設計
```typescript
type GpsSession = {
  id: string;
  startTime: number;
  endTime: number;
  coordinates: { latitude: number; longitude: number }[];
};
```

## 🔧 開発中に直面した技術的課題

### 課題1: GPS精度とバッテリー消費のトレードオフ

**問題**
GPS取得の精度を上げるほどバッテリー消費が増加し、
長時間の走行でスマホが熱くなる問題が発生した。

**解決策**
`Accuracy.High`から`Accuracy.Balanced`に変更し、
取得頻度も「時間間隔」から「距離間隔（5m移動ごと）」に切り替えた。
これによりバッテリー消費を抑えながら、
ヒートマップの精度に必要十分なGPSデータを取得できるようになった。

**学び**
ユーザー体験に影響しない範囲でのパフォーマンス最適化の重要性を学んだ。
「完璧な精度」より「十分な精度で軽快に動く」ことがプロダクトの価値につながる。

---

### 課題2: 「同じ道を走った」という判定の難しさ

**問題**
GPSは毎回数メートルの誤差が生じるため、
同じ道を走っても座標が毎回異なる。
「同じ道を走った」という判定をどう実装するかが最大の技術的課題だった。

**解決策**
地図を30m×30mのグリッド（マス目）に分割し、
GPS座標をグリッドIDに変換することで近似的に「同じ場所」を判定した。
完全な道路マッチングは実装コストが高いため、
MVPではグリッド方式でトレードオフを取る判断をした。

**学び**
完璧な実装を追求するより、
「ユーザーが体験として満足できる精度」を優先する
プロダクト思考の重要性を学んだ。

---

### 課題3: パフォーマンス最適化（大量データの再計算）

**問題**
走行セッションが増えるにつれ、
全セッションのグリッドデータを毎回再計算するため
地図の描画が遅くなる問題が発生した。

**解決策**
ReactのuseMemoを使い、
savedSessionsまたはlocationsが変化した時だけ
グリッドの通過回数を再計算するように最適化した。
これにより不要な再計算を防ぎ、描画パフォーマンスを改善した。

**学び**
Reactのレンダリング最適化の重要性と、
データ量が増えた時のパフォーマンス問題を
事前に設計段階で考慮することの大切さを学んだ。

### 収集する情報
futoは以下の情報を収集します。
・位置情報（GPS）：走行ルートの記録のために使用します。

### 情報の使用目的
収集した位置情報はお使いの端末内にのみ保存され、
外部サーバーへの送信は一切行いません。

### 第三者への提供
収集した情報を第三者に提供・販売することはありません。
